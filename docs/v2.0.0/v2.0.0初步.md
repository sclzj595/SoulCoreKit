## v2.0.0 — 架构升级 + 数据层增强 (SpringBoot 风格启动器)
目标 : 让框架真正实现"一键启动" + ORM 反射自动化 + 多数据库驱动 + 迁移系统

### 需求清单 — 架构升级
ID 需求 描述 优先级 2.0.1 Application 启动器 sc::Application::run(argc, argv) 一行启动，自动扫描模块、初始化 DI 容器、启动 HTTP Server P0 2.0.2 application.yml 配置 YAML 格式配置加载，支持 server.port 、 datasource.* 、 logging.level 等标准键 P0 2.0.3 自动装配 (AutoConfiguration) 基于条件注解 ( @ConditionalOnClass 等) 的自动装配机制，扫描 soul.factories 文件 P0 2.0.4 Scaffold 重构 将现有 Scaffold 类升级为 Application 的底层引擎，保持向后兼容 P0 2.0.5 Profile 环境隔离 支持 application-dev.yml / application-prod.yml 分层配置 + --spring.profiles.active=dev 命令行 P1 2.0.6 Banner 启动横幅 可自定义的 ASCII Art 启动 Banner P2 2.0.7 StartupInfoLogger 启动时打印端口、模块列表、耗时等诊断信息 P2

### 需求清单 — 数据层增强
ID 需求 描述 优先级 2.0.8 ORM 反射自动化 基于宏/模板自动生成 getPropertyImpl / setPropertyImpl ，消除手动 boilerplate P0 2.0.9 数据库迁移 (Migration) Schema 版本升级/回滚，类似 Flyway 机制 P0 2.0.10 查询构建器 (QueryBuilder) 类型安全的条件构造，防 SQL 注入 P0 2.0.11 查询结果缓存 ORM 级别查询缓存，支持 TTL + 失效策略 P1 2.0.12 PostgreSQL 驱动 在 SQLite 之外增加 PostgreSQL 官方驱动 P1 2.0.13 MySQL 驱动 增加 MySQL/MariaDB 驱动 P1 2.0.14 连接池动态扩缩 基于等待队列长度自动扩缩（已在 v1.9.4 完成 API） P2

### 模块影响
